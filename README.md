# SpaceNG

SpaceNG is a PERN stack marketplace for hourly/half-day workspace bookings in Abuja, Nigeria.

## Tech Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express
- Database: PostgreSQL (Neon)

## Getting Started
1. Clone the repository.
2. Install dependencies in `server` and `client` directories.
3. Copy `.env.example` to `.env` in both directories and update the variables.
4. Run `npm start` in `server` and `npm run dev` in `client`.
