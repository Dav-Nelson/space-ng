# Design Review: SpaceNG

## Core Concept
SpaceNG is an hourly workspace booking marketplace connecting professionals in Abuja with underutilized spaces.

## User Experience
- **Professionals:** Need quick access to productive, quiet spaces without long-term commitments.
- **Venues:** Want to monetize empty meeting rooms or quiet corners during off-peak hours.

## Key Features (MVP)
- **Search & Filter:** By location, hourly rate, amenities (Wi-Fi, AC, power, coffee).
- **Booking Engine:** Real-time availability, booking slots (hourly/half-day).
- **User Dashboard:** View upcoming bookings, history, profile management.
- **Venue Dashboard:** Manage listings, availability calendar, booking requests.
- **Payments:** Secure transaction processing for hourly bookings.
